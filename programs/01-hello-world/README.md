# 01. Hello, World!

**Difficulty:** Beginner
**Concepts:** Basics, Input/Output

## Description
Your first C++ program. Learn the basics of compiling, running and printing to the console.

## Code
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
```

## Expected Output
```
Hello, C++!
```

## Explanation
Every C++ program starts execution at main(). The <iostream> header brings in cout, the standard output stream, and endl flushes the stream and moves to a new line.
